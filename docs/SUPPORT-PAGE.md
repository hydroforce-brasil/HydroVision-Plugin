# Proposta de página de suporte HydroVision

Rascunho para incorporar ao site Hydroforce existente. Ainda não publicado.
Canal de atendimento confirmado pelo mantenedor: `contato@hydroforce.com.br`.
Não preencher `supportURL` até abrir e conferir a página real em HTTPS.

Caminho sugerido, a criar no site: `/pt-BR/hydrovision/suporte`.
Este caminho é uma proposta, não um endereço verificado.

## Conteúdo proposto

### Suporte do HydroVision no ChatGPT

Precisa de ajuda para conectar sua conta HydroVision, consultar dados ou gerar
um relatório pelo ChatGPT? Entre em contato com a equipe Hydroforce pelo canal
indicado nesta página.

**E-mail de suporte:** [contato@hydroforce.com.br](mailto:contato@hydroforce.com.br).

Ao relatar um problema, informe:

- se o problema ocorre no site HydroVision ou no plugin do ChatGPT;
- empresa vinculada à sua conta e descrição do problema;
- data, horário e mensagem de erro, se houver;
- passos para reproduzir a falha; em problemas com relatório, período e formato solicitado.

Não envie senha, token de acesso ou códigos de autenticação. Se enviar uma captura
de tela, oculte credenciais e dados de terceiros que não sejam necessários ao atendimento.

### Acesso e conexão

O plugin exige uma conta HydroVision autorizada. Entre com sua própria conta.
Se uma empresa ou registro não aparecer, confira suas permissões com o responsável
pelo acesso na sua organização. Instalar o plugin não concede novas permissões.

As ferramentas do plugin consultam dados em modo somente leitura. A criação de
anexos e a exibição de imagens dependem dos recursos disponíveis no cliente ChatGPT.
