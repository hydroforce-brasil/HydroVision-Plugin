# Recursos do cliente atual

Use as tools e os recursos realmente disponíveis nesta sessão. Detecte recursos de
execução de código, criação de arquivos, renderização e apresentação de imagens antes
de prometer o formato final. O MCP fornece dados e evidências; o cliente compõe a entrega.

Não presuma que uma capacidade de outro produto esteja instalada. A existência de uma
skill não habilita automaticamente Word, PowerPoint, PDF, planilhas ou acesso ao disco.
Use o modelo incorporado e os recursos de arquivo do ambiente. Se não houver execução
ou exportação, explique a limitação sem anunciar um arquivo que não foi produzido.

Para imagens, prefira os blocos nativos retornados pelo cliente. Caso o executor receba
bytes, materialize-os e use uma referência de imagem real, incorporada junto ao texto.
Não construa URLs a partir de URIs `hydrovision://` nem transforme URL assinada em mídia
externa persistente. Fotos principais ficam junto aos achados; demais no apêndice visual
ou galeria no chat. Se não houver bytes ou renderização, identifique a falha específica.

Use OAuth pela conexão configurada. Client IDs são públicos e específicos de cada
cliente; não substitua a autenticação por tokens fixos nem altere permissões ou seleção
da empresa para contornar uma consulta. Prefixos das tools variam; descubra os nomes reais.
